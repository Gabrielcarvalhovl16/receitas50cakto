LANDING PAGE — 50 RECEITAS PARA DEIXAR SUA ALIMENTAÇÃO MAIS LEVE

PRONTO PARA VERCEL (SITE ESTÁTICO)

1) CHECKOUT
Abra script.js e altere:
const CHECKOUT_URL = "";
para o link real do checkout.

2) SUPORTE
No index.html, procure por:
"Adicione aqui o e-mail/WhatsApp de suporte"
e troque pelos dados reais.

3) GARANTIA
A página exibe garantia de 7 dias. Confirme que esta é a política real da oferta antes de publicar.

4) DEPOIMENTOS
Não foram criados depoimentos fictícios. Quando houver feedbacks reais, adicione uma seção de prova social com prints reais.

5) DEPLOY NA VERCEL
- Extraia o ZIP.
- Importe a pasta no seu repositório GitHub OU faça o deploy da pasta pela Vercel.
- Framework Preset: Other.
- Build Command: deixar vazio.
- Output Directory: deixar vazio.
